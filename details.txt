The project Lingesh R is most proud of is the AI-enabled real-time sleep apnea detection system.

This system was built to solve a real-world healthcare problem where people suffering from sleep apnea may not receive timely help.

The system integrates IoT sensors with machine learning to monitor breathing patterns and vital signals.

It sends real-time alerts to guardians when an apnea event is detected.

This project combines AI, IoT hardware, and real-world impact.


In the sleep apnea project, Lingesh R made a key technical decision to use server-based inference instead of deploying the model directly on ESP32.

This decision was made because ESP32 has limited computational power.

By using a Flask-based backend server, he ensured better performance, higher accuracy, and reliable real-time alerting.


One of the biggest challenges Lingesh R faced was preprocessing the sleep apnea dataset. The data was initially in .npy format, which he converted into 3-minute audio files. He then split the audio into 10-second clips and manually labeled each segment as apnea or non-apnea. This process was time-consuming but essential for building an accurate model.
