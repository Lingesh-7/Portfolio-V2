Real-Time Sleep Apnea Detection and Monitoring

Wearable system in active development that detects potential apnea events from breathing audio, heart rate and SpO₂ in real time.

TensorFlowFlaskESP32IoT
Project files ↗
  • Detects potential apnea events using breathing audio, heart rate and SpO₂ signals in real time.
  • Built the dataset from raw polysomnography breathing recordings, segmented into 10-second audio frames and labelled across 103,210 samples.
  • Extracted MFCC features and trained a TensorFlow MLP classifier that reaches 81% accuracy on apnea event detection.
  • Sensors are an INMP441 microphone and a MAX30102 for heart rate and SpO₂, streaming to an ESP32.
  • Inference runs on a Flask server instead of the ESP32, which has limited compute, for better accuracy and reliable alerts.
  • Sends real-time alerts to guardians when an apnea event is detected.
  • Won Best Real World Applicability at a national ideathon. Documented in a 2025 research report, with a paper in preparation. Still under active development.
